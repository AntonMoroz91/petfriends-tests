PetFriends — автоматизация тестирования
=======================================

О проекте
---------
Автотесты для сайта PetFriends (учебный проект Skillfactory).
Проект выполнен в рамках модуля 30 курса «Тестировщик-автоматизатор на Python».

Основная цель — проверить страницу "Мои питомцы" пользователя:
- соответствие количества питомцев статистике,
- наличие фото хотя бы у половины питомцев,
- заполненность данных (имя, порода, возраст),
- уникальность имён,
- отсутствие дубликатов питомцев.

Технологии
----------
- Python 3.11
- Selenium WebDriver
- pytest
- Google Chrome + ChromeDriver
- Явные и неявные ожидания (WebDriverWait, implicitly_wait)

Установка и запуск
------------------
1. Клонируйте репозиторий или создайте проект в PyCharm
2. Установите зависимости:
   pip install selenium pytest
3. Убедитесь, что ChromeDriver установлен и доступен в PATH
4. Укажите свои данные в файле settings.py:
   VALID_EMAIL = "your_email@mail.ru"
   VALID_PASSWORD = "your_password"
   BASE_URL = "https://petfriends.skillfactory.ru"
5. Запустите тест:
   pytest test_pets.py -v -s
