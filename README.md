PetFriends — автоматизация тестирования
=======================================

▎О проекте
----------
Автотесты для сайта PetFriends (учебный проект Skillfactory).
Проект выполнен в рамках модуля 30 курса «Тестировщик-автоматизатор на Python».

Основная цель — проверить страницу "Мои питомцы" пользователя:
- ✅ соответствие количества питомцев статистике
- 🖼️ наличие фото хотя бы у половины питомцев
- 📝 заполненность данных (имя, порода, возраст)
- 🏷️ уникальность имён
- 🔄 отсутствие дубликатов питомцев

▎Технологии
-----------
- 🐍 Python 3.11
- 🌐 Selenium WebDriver
- 🧪 pytest
- 🌎 Google Chrome + ChromeDriver
- ⏳ WebDriverWait (явные ожидания)
- ⏱️ implicitly_wait (неявные ожидания)

▎Инструменты
------------
- 🔍 Element Locator — поиск CSS-селекторов и XPath
- 🛠️ Chrome DevTools — анализ DOM-структуры страницы

▎Установка и запуск
-------------------
- 📥 git clone https://github.com/AntonMoroz91/petfriends-tests.git
- 📁 cd petfriends-tests
- 📦 pip install selenium pytest
- ▶️ pytest test_pets.py -v -s

▎Важно
------
Перед запуском укажите свои данные в файле settings.py:

VALID_EMAIL    = "ваш_email@mail.ru"
VALID_PASSWORD = "ваш_пароль"
BASE_URL       = "https://petfriends.skillfactory.ru"
