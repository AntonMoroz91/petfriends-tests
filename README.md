PetFriends — автоматизация тестирования
=======================================

▎О проекте
----------
Автотесты для сайта PetFriends (учебный проект Skillfactory).
Проект выполнен в рамках модуля 30 курса «Тестировщик-автоматизатор на Python».

Цель — проверить страницу "Мои питомцы":
- ✅ соответствие количества питомцев статистике
- 🖼️ наличие фото хотя бы у половины питомцев
- 📝 заполненность данных (имя, порода, возраст)
- 🏷️ уникальность имён
- 🔄 отсутствие дубликатов


▎Технологии и инструменты
-------------------------
- 🐍 Python 3.11
- 🌐 Selenium WebDriver
- 🧪 pytest
- 🔍 Element Locator (поиск локаторов)
- ⏳ WebDriverWait + implicitly_wait


▎Установка и запуск
-------------------
- git clone https://github.com/AntonMoroz91/petfriends-tests.git
- cd petfriends-tests
- pip install selenium pytest
- pytest test_pets.py -v -s


▎Важно
------
Данные для входа в settings.py:

    VALID_EMAIL    = "email@mail.ru"
    VALID_PASSWORD = "пароль"
    BASE_URL       = "https://petfriends.skillfactory.ru"
